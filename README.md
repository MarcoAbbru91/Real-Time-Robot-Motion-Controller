# Real-Time-Robot-Motion-Controller
**Goal of this project**

Implementing a real-time differential-drive robot controller with modern C++ and FreeRTOS. Features PID motor control, trajectory tracking, robot simulation, and Python-based visualization, with a modular architecture designed for future hardware integration.


## 🚀 Planned Roadmap

- [ ] **1. FreeRTOS integration** – Implement tasks, scheduling, and inter-task communication in C.
- [ ] **2. C++ Development** – Implement robot dynamics, motor models, and motion controllers.
- [ ] **3. PC Simulation & Testing** – Validate robot behavior and control algorithms.
- [ ] **4. Python GUI** – Visualize robot motion and trajectory tracking.
- [ ] **5. FreeRTOS Integration** – Deploy C++ controllers on STM32 and connect to the PC simulator.
- [ ] **6. Hardware Integration (possibly in future)** – Replace simulated motors and encoders with real hardware.
